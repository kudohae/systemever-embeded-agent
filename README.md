# SystemEver AI 에이전트 화면 목업

SystemEver 화면 구성을 참고해 만든 정적 HTML 목업입니다. 영림원소프트랩의 공식 화면이 아니며, SystemEver 또는 AI API와 연결되지 않습니다. 화면의 버튼과 표시된 업무 처리는 작동하지 않습니다.

| 화면 | 파일 |
| --- | --- |
| 자연어 업무 대화 | `conversation.html` |
| 에이전트 등록안 | `agent_register.html` |
| 조직 승인 및 ID 발급 | `allow_agent.html` |
| 조건 감지와 실행 이력 | `condition_log.html` |
| 구매요청 초안 | `request_draft.html` |

각 HTML 파일을 브라우저에서 열면 됩니다. 다섯 화면은 `styles.css`를 공유합니다.
