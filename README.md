# SystemEver AI 에이전트 화면 목업

제공된 SystemEver 재고조회·사원명단조회·사원상세 화면을 참고해 만든 HTML 목업입니다. 교육용 사이트의 로그인 후 화면을 직접 탐색한 결과물은 아닙니다. 영림원소프트랩의 공식 화면이 아니며, SystemEver 또는 AI API와 연결되지 않습니다. 모듈 메뉴, 에이전트 명단→상세 이동, 상세 탭 전환은 작동하고, 표시된 업무 처리와 조회 버튼은 작동하지 않습니다.

| 화면 | 파일 |
| --- | --- |
| 재고현황조회 시작 화면 | `index.html` |
| 자연어 업무 대화 | `conversation.html` |
| AI 에이전트 현황 목록 | `agent_list.html` |
| AI 에이전트 상세정보 | `agent_detail.html` |
| 에이전트 등록안 | `agent_register.html` |
| 조직 승인 및 ID 발급 | `allow_agent.html` |
| 조건 감지와 실행 이력 | `condition_log.html` |
| 구매요청 초안 | `request_draft.html` |

`index.html`을 브라우저에서 열어 시작합니다. 왼쪽 모듈 버튼을 누르면 확장 메뉴가 열리고, AI 모듈에서 에이전트 현황·등록안·조직 승인·실행 이력으로 이동할 수 있습니다. 에이전트 현황의 행을 더블클릭하면 상세 탭이 열리며, 상세정보의 항목별 탭을 전환할 수 있습니다. 상단 `AI에게 업무 요청`은 대화 화면으로, 구매/수입 모듈의 구매요청 초안은 해당 문서 화면으로 이동합니다. 화면은 `styles.css`와 `navigation.js`를 공유합니다.
